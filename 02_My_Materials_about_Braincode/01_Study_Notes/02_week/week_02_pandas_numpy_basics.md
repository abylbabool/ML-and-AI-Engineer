## Часть 1. Загрузка и знакомство с таблицей

### Базовые понятия Python, которые встретятся сразу

| Запись | Что это | Пример |
|---|---|---|
| `# текст` | Комментарий. Python его не выполняет | `# загрузка данных` |
| `имя = значение` | **Переменная**: имя, под которым хранится объект | `df = ...` |
| `'...'` или `"..."` | **Строка** (тип `str`). Кавычки равноправны | `"Age"` |
| `имя(...)` | **Вызов функции**. Скобки = «выполни» | `print("Привет")` |
| `объект.имя(...)` | **Метод**: функция, которая принадлежит объекту | `df.head()` |
| `объект.имя` без скобок | **Атрибут**: готовое свойство объекта, ничего не выполняет | `df.shape` |
| `f(5, random_state=42)` | **Аргументы**: позиционный (`5`) и именованный (`random_state=42`) | `df.sample(5, random_state=42)` |
| `x[0]` | **Индексация**: взять элемент по номеру. Нумерация с 0 | `df.shape[0]` |

Два правила на всю неделю:

- **Вывод в Jupyter.** Автоматически показывается только значение **последней строки ячейки**. Поэтому `df.head()` в конце ячейки выводит таблицу без `print`. Чтобы показать что-то из середины ячейки — `print(...)` или `display(...)`. Где в конспекте несколько выводов подряд — это отдельные ячейки или явный `display`/`print`.
- **Исходник не меняется.** `head`, `sort_values`, фильтры, `dropna`, `fillna` и т.п. возвращают **новый** объект, `df` остаётся прежним. Чтобы сохранить результат, его присваивают: `by_fare = df.sort_values("Fare")`.

### 1.1 Импорт библиотек

**Что это.** `import` подключает внешнюю библиотеку, чтобы использовать её функции в коде.

**Зачем.** В «голом» Python нет таблиц и графиков. pandas даёт таблицы, NumPy — быстрые массивы чисел, matplotlib — графики.

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
from IPython.display import display
```

| Строка | Разбор |
|---|---|
| `import pandas as pd` | `import`, `as` — ключевые слова Python. `pandas` — библиотека. `pd` — короткое имя (псевдоним). Дальше везде пишем `pd.`, а не `pandas.` |
| `import numpy as np` | То же для NumPy. `np` — общепринятый псевдоним |
| `import matplotlib.pyplot as plt` | `matplotlib` — библиотека, `pyplot` — её модуль (часть) для рисования. Точка здесь означает «модуль внутри библиотеки» |
| `from IPython.display import display` | `from ... import ...` берёт из модуля одну функцию. После этого пишем просто `display(...)`, без префикса |

`display` нужна, чтобы показать таблицу **не в последней строке** ячейки: Jupyter автоматически выводит только последнюю.

**Что вернётся.** Ничего не выводится. Если библиотека не установлена — ошибка `ModuleNotFoundError`.

**Типичные ошибки.**
- Не запустили ячейку с импортом → `NameError: name 'pd' is not defined`. Ноутбук помнит только выполненные ячейки.
- `ModuleNotFoundError: No module named 'pandas'` — библиотека не установлена в окружении (см. SETUP.md).

### 1.2 Загрузка CSV в DataFrame

**Что это.** `pd.read_csv()` читает CSV-файл (текст, где значения разделены запятыми) и превращает его в **DataFrame** — таблицу pandas.

**Зачем.** Почти любой анализ начинается с загрузки выгрузки в память как таблицы.

```python
df = pd.read_csv('https://raw.githubusercontent.com/jorisvandenbossche/pandas-tutorial/master/data/titanic.csv')
df.head()
```

| Фрагмент | Разбор |
|---|---|
| `pd.read_csv` | `pd` — pandas (из `import pandas as pd`). `read_csv` — **функция** pandas |
| `'https://...csv'` | **Аргумент** — строка с адресом. Можно передать и путь к локальному файлу: `'data/titanic.csv'` |
| `df = ...` | Результат сохраняем в **переменную** `df` (сокращение от DataFrame — общепринятое имя) |
| `df.head()` | **Метод** объекта `df`: первые строки таблицы (подробно в 1.3) |

**Что вернётся.** Объект типа `DataFrame`. Структура: строки, столбцы с названиями и **индекс** — метки строк слева (здесь `0, 1, 2, ...`).

```text
type(df)  →  <class 'pandas.DataFrame'>
```

> В pandas 2.x (часто в Colab) выводится `pandas.core.frame.DataFrame` — это тот же класс.

**Что за данные.** Одна строка — один пассажир. Это конкретный набор записей, а не полный список людей на борту.

| Поле | Значение |
|---|---|
| `PassengerId`, `Name` | Идентификатор и имя |
| `Survived` | 1 — выжил, 0 — нет |
| `Pclass` | Класс билета 1/2/3 — **категория**, хоть и записан числом |
| `Sex`, `Age` | Пол, возраст в годах |
| `SibSp`, `Parch` | Число братьев/сестёр/супругов и родителей/детей на борту |
| `Ticket`, `Fare`, `Cabin` | Билет, стоимость, каюта |
| `Embarked` | Порт посадки: C — Cherbourg, Q — Queenstown, S — Southampton |

`NaN` (Not a Number) — так pandas показывает **пропуск**: значение неизвестно. Это не ноль.

**Типичные ошибки.**
- Регистр в названиях: `df['age']` → `KeyError: 'age'`. Правильно `df['Age']`.
- Нет интернета или неверный путь → ошибка загрузки (`URLError`, `FileNotFoundError`). Ячейку нужно перезапустить после исправления.
- `df = pd.read_csv(...)` без вызова `head()` ничего не показывает — это нормально, данные загружены в переменную.

**Банковский пример.** Выгрузка клиентов из CRM:

```python
clients = pd.read_csv("clients.csv")
```

`clients.csv` (5 строк, сделан для примера):

```text
client_id,segment,city,balance_kzt,credit_limit,last_txn_date
1001,mass,Almaty,250000.50,500000,2026-11-10
1002,premium,Astana,4800000.00,,2026-11-15

1004,sme,Almaty,950000.75,2000000,2026-11-18
1005,mass,Shymkent,,150000,2026-10-02
```

Две запятые подряд (`,,`) — пустое поле, после загрузки станет `NaN`.

### 1.3 Просмотр строк: head, tail, sample

**Что это.** Методы DataFrame, которые возвращают часть строк таблицы.

**Зачем.** Таблицу в 891 строку целиком не смотрят. Первые, последние и случайные строки показывают формат данных, пропуски и странности.

В ноутбуке это три отдельные ячейки — в одной ячейке вывелась бы только последняя таблица.

```python
df.head()                        # ячейка 1: первые 5 строк
```

```python
df.tail(5)                       # ячейка 2: последние 5 строк
```

```python
df.sample(5, random_state=42)    # ячейка 3: 5 случайных строк, воспроизводимо
```

| Фрагмент | Разбор |
|---|---|
| `head()` | Метод. Без аргумента — 5 строк (значение по умолчанию). `head(3)` — 3 строки |
| `tail(5)` | Метод. `5` — позиционный аргумент: сколько строк с конца |
| `sample(5, ...)` | Метод. Случайные 5 строк |
| `random_state=42` | Именованный аргумент. Фиксирует «случайность»: при повторном запуске те же строки. Без него каждый запуск даёт новые строки. `42` — просто договорённое число, подойдёт любое |

**Что вернётся.** Новый `DataFrame` с выбранными строками. Индекс сохраняет исходные метки строк.

### 1.4 Размер и названия столбцов: shape, columns

**Что это.** `shape` и `columns` — **атрибуты** DataFrame: готовые сведения о таблице, вызываются без скобок.

**Зачем.** Сразу знать, сколько записей и какие поля есть, — до любых расчётов.

```python
print("Строк:", df.shape[0])
print("Столбцов:", df.shape[1])
```

| Фрагмент | Разбор |
|---|---|
| `print(...)` | **Встроенная функция Python** (не pandas). Печатает значения через пробел |
| `"Строк:"` | Первый аргумент — строка-подпись |
| `df.shape` | Атрибут. Возвращает **кортеж** (`tuple`) — неизменяемую пару значений `(строки, столбцы)` |
| `df.shape[0]` | Индексация кортежа: элемент с номером 0 — число строк |
| `df.shape[1]` | Элемент с номером 1 — число столбцов |

Вывод:

```text
Строк: 891
Столбцов: 12
```

Само `df.shape` вернёт `(891, 12)`.

```python
df.columns.tolist()
```

| Фрагмент | Разбор |
|---|---|
| `df.columns` | Атрибут. Объект pandas `Index` — названия столбцов |
| `.tolist()` | Метод `Index`: превращает его в обычный **список** Python (`list`) |

Вызовы идут по цепочке слева направо: сначала `df.columns`, затем у результата вызывается `.tolist()`.

Вывод (тип `list`):

```text
['PassengerId', 'Survived', 'Pclass', 'Name', 'Sex', 'Age', 'SibSp', 'Parch', 'Ticket', 'Fare', 'Cabin', 'Embarked']
```

Список удобно копировать, чтобы не ошибиться в регистре при выборе колонок.

**Типичные ошибки.**
- `df.shape()` → `TypeError: 'tuple' object is not callable`. `shape` — атрибут, скобки не нужны.
- `df.shape[1]` принять за строки. Порядок всегда `(строки, столбцы)`.
- Путать `len(df)` и `df.shape`: `len(df)` (встроенная функция Python) даёт только число строк — `891`.

**Банковский пример.** Сверка с источником: если в CRM 120 000 активных клиентов, а `shape[0]` = 119 400 — часть записей потерялась при выгрузке. Это первая проверка любой интеграции.

### 1.5 Типы и заполненность: dtypes, info

**Что это.** `dtypes` — атрибут с типом хранения каждого столбца. `info()` — метод, который печатает сводку: типы, число заполненных значений, память.

**Зачем.** Тип определяет, какие операции возможны. Число заполненных значений сразу показывает пропуски.

```python
df.dtypes
```

`dtypes` — атрибут, возвращает `Series` (столбец pandas с подписями): название колонки → тип.

```text
PassengerId      int64
Survived         int64
Pclass           int64
Name               str
Sex                str
Age            float64
SibSp            int64
Parch            int64
Ticket             str
Fare           float64
Cabin              str
Embarked           str
dtype: object
```

| Тип | Значение |
|---|---|
| `int64` | Целые числа |
| `float64` | Дробные числа. Целочисленный столбец с `NaN` становится `float64` (текстовый остаётся `str`) |
| `str` | Текст. В pandas 2.x (Colab) показывается как `object` |

Последняя строка `dtype: object` — тип самого результата `dtypes`, к данным Titanic не относится.

### 2.1 describe для числовых столбцов

**Что это.** `describe()` — метод DataFrame. Считает набор описательных показателей для каждого числового столбца.

**Зачем.** Одной командой увидеть масштаб, центр и разброс значений, а также подозрительные минимумы и максимумы.

```python
df.describe().round(2)
```

| Фрагмент | Разбор |
|---|---|
| `df.describe()` | Метод. Без аргументов берёт только числовые столбцы (`int64`, `float64`) |
| `.round(2)` | Метод pandas у результата: округлить до 2 знаков. Это цепочка: `describe()` вернул таблицу, у неё вызываем `round` |

**Что вернётся.** Новый `DataFrame`: строки — показатели, столбцы — исходные числовые колонки.

| | PassengerId | Survived | Pclass | Age | SibSp | Parch | Fare |
|---|---|---|---|---|---|---|---|
| count | 891.00 | 891.00 | 891.00 | 714.00 | 891.00 | 891.00 | 891.00 |
| mean | 446.00 | 0.38 | 2.31 | 29.70 | 0.52 | 0.38 | 32.20 |
| std | 257.35 | 0.49 | 0.84 | 14.53 | 1.10 | 0.81 | 49.69 |
| min | 1.00 | 0.00 | 1.00 | 0.42 | 0.00 | 0.00 | 0.00 |
| 25% | 223.50 | 0.00 | 2.00 | 20.12 | 0.00 | 0.00 | 7.91 |
| 50% | 446.00 | 0.00 | 3.00 | 28.00 | 0.00 | 0.00 | 14.45 |
| 75% | 668.50 | 1.00 | 3.00 | 38.00 | 1.00 | 0.00 | 31.00 |
| max | 891.00 | 1.00 | 3.00 | 80.00 | 8.00 | 6.00 | 512.33 |

| Показатель | Смысл |
|---|---|
| `count` | Число **известных** значений (без `NaN`). У `Age` 714, а не 891 |
| `mean` | Среднее арифметическое |
| `std` | Стандартное отклонение — типичный разброс вокруг среднего: корень из среднего квадрата отклонений. pandas делит на `n − 1` (подробнее в 5.5) |
| `min` / `max` | Границы |
| `25%` | Первый квартиль: четверть значений не больше этого числа |
| `50%` | Медиана: половина значений не больше |
| `75%` | Третий квартиль |

Часть столбцов здесь бессмысленна: среднее `PassengerId` (446) — середина нумерации, `Pclass` 2.31 — «средний класс», которого не бывает. `Survived` — исключение: для кода 0/1 среднее равно доле единиц, т.е. 38% выживших в наборе.

Поэтому выбираем только измеряемые величины:

```python
df[["Age", "Fare", "SibSp", "Parch"]].describe().round(2)
```

`df[[...]]` — выбор нескольких столбцов. Внутренние `[...]` — **список** Python (упорядоченный набор значений через запятую), внешние — обращение к `df`. Подробно в 2.4. Результат — те же четыре столбца с теми же числами, что в таблице выше, без ID и категорий.

Что читается:
- `Fare`: среднее 32.20 более чем вдвое выше медианы 14.45, `max` 512.33 при `75%` = 31. Немного очень дорогих билетов тянут среднее вверх.
- `Fare` `min` = 0.00 — таких билетов 15. Это не обязательно ошибка; сначала смотрят на сами записи.
- `Age` `min` = 0.42 — младенец около 5 месяцев, возраст хранится дробным.
- `Parch` 75% = 0: минимум три четверти пассажиров ехали без родителей/детей.

**Типичные ошибки.**
- Читать `count` как число строк. Это число известных значений.
- Делать выводы по `mean` идентификаторов и категорий (`PassengerId`, `Pclass`).
- Объявлять `max` выбросом-ошибкой, не посмотрев записи.

### 2.2 describe для текстовых столбцов

**Что это.** Тот же `describe()`, вызванный для текстовых столбцов, считает другие показатели — частотные.

**Зачем.** Быстро понять, сколько разных значений в категории и какое самое частое.

```python
df[["Sex", "Embarked", "Cabin"]].describe()
```

**Что вернётся.** `DataFrame` с четырьмя строками.

| | Sex | Embarked | Cabin |
|---|---|---|---|
| count | 891 | 889 | 204 |

| Показатель | Смысл | Пример |

### 2.3 Отдельные показатели: mean, median, min, max, quantile

**Что это.** Методы `Series` (одного столбца), которые считают по одному показателю.

**Зачем.** Когда нужно конкретное число для вывода или дальнейших расчётов, а не вся таблица `describe`.

```python
print("Средний возраст:", round(df["Age"].mean(), 2))
print("Медианный возраст:", df["Age"].median())
print("Минимум и максимум:", df["Age"].min(), df["Age"].max())
```

| Фрагмент | Разбор |
|---|---|
| `df["Age"]` | Один столбец — объект `Series` (см. 2.4) |
| `.mean()` | Метод pandas: среднее. Пропуски `NaN` пропускает автоматически |
| `round(x, 2)` | **Встроенная функция Python**: округлить число `x` до 2 знаков. Не путать с методом pandas `.round(2)` из 2.1: функция пишется перед значением, метод — после точки |
| `.median()` | Медиана |
| `.min()`, `.max()` | Минимум и максимум |
| `print(a, b, c)` | Несколько аргументов печатаются через пробел |

Вывод:

```text
Средний возраст: 29.7
Медианный возраст: 28.0
Минимум и максимум: 0.42 80.0
```

**Что вернётся.** Одно число (тип `numpy.float64` — число из NumPy, ведёт себя как обычное дробное).

```python
df["Fare"].quantile([0.25, 0.5, 0.75, 0.9]).round(2)
```

| Фрагмент | Разбор |
|---|---|
| `.quantile(...)` | Метод: квантили — значения, ниже которых лежит заданная доля данных |
| `[0.25, 0.5, 0.75, 0.9]` | Аргумент — **список** доль. `0.9` = 90-й процентиль |
| `.round(2)` | Метод pandas, округление результата |

Вывод — `Series`, где индекс — доли, значения — стоимости:

```text
0.25     7.91
0.50    14.45
0.75    31.00
0.90    77.96
Name: Fare, dtype: float64
```

90% билетов стоят не больше 77.96, а максимум — 512.33. Квантиль 0.5 совпадает с медианой.

`Name: Fare` — имя `Series` (из какого столбца), `dtype: float64` — тип значений.

**Mean или median.**

| | Среднее | Медиана |
|---|---|---|
| Отвечает на | «Сколько на одного, если поделить поровну» | «Значение посередине» |
| Чувствительность к крайним значениям | Высокая | Низкая |
| Fare в Titanic | 32.20 | 14.45 |

Когда среднее заметно больше медианы — есть длинный «хвост» больших значений.

**Типичные ошибки.**
- `df["Age"].mean` без скобок — получите описание метода, а не число.
- Сравнивать показатели с разным `count`: `Age` посчитан по 714 значениям, `Fare` — по 891.
- `quantile(90)` вместо `quantile(0.9)` → `ValueError: percentiles should all be in the interval [0, 1]`.

**Банковский пример.**

```python
print(txns["amount_kzt"].median())               # типичная сумма операции
txns["amount_kzt"].quantile([0.5, 0.95, 0.99])   # порог «крупных» операций
```

Квантиль 0.99 по суммам — простой способ задать порог для ручной проверки крупных транзакций, не выдумывая число «на глаз».

**Что это.** `Series` — один столбец с индексом. `DataFrame` — таблица из нескольких `Series` с общим индексом.

**Зачем.** От типа зависит, какие методы доступны и как выглядит вывод. Многие ошибки новичков — из-за путаницы одинарных и двойных скобок.

```python
ages = df["Age"]
print(type(ages))
ages.head()
```

| `ages = ...` | Сохраняем столбец в переменную, чтобы не писать `df["Age"]` каждый раз |
| `type(...)` | **Встроенная функция Python**: тип объекта |
| `ages.head()` | У `Series` тоже есть `head` |

Вывод:

```text
<class 'pandas.Series'>

0    22.0
1    38.0
2    26.0
3    35.0
4    35.0
Name: Age, dtype: float64
```

```python
passenger_view = df[["Name", "Age", "Sex", "Pclass"]]
passenger_view.head()
```

### 2.5 Строки и столбцы: loc и iloc

**Что это.** `loc` и `iloc` — **индексаторы** DataFrame: атрибуты, после которых ставят квадратные скобки `[строки, столбцы]`. `loc` выбирает по **меткам** (индекс и названия), `iloc` — по **позициям** (номера с 0).

**Зачем.** Выбрать одновременно нужные строки и нужные столбцы. В части 3 через `loc` будут работать фильтры.

```python
df.loc[0:4, ["Name", "Age", "Fare"]]
```

| Фрагмент | Разбор |
|---|---|
| `df.loc` | Атрибут-индексатор. Скобки квадратные, не круглые |
| `0:4` | **Срез** (`начало:конец`) по меткам индекса. У `loc` правая граница **включается** → строки 0, 1, 2, 3, 4 |
| `,` | Разделяет «какие строки» и «какие столбцы» |
| `["Name", "Age", "Fare"]` | Список названий столбцов |

| | Name | Age | Fare |
|---|---|---|---|
| 0 | Braund, Mr. Owen Harris | 22.0 | 7.2500 |
| 1 | Cumings, Mrs. John Bradley (Florence Briggs Th... | 38.0 | 71.2833 |
| 2 | Heikkinen, Miss. Laina | 26.0 | 7.9250 |
| 3 | Futrelle, Mrs. Jacques Heath (Lily May Peel) | 35.0 | 53.1000 |
| 4 | Allen, Mr. William Henry | 35.0 | 8.0500 |

```python
df.iloc[0:4, 0:3]
```

| Фрагмент | Разбор |
|---|---|
| `df.iloc` | Индексатор по позициям |
| `0:4` | Позиции 0, 1, 2, 3. Правая граница **не включается** (как везде в Python) |
| `0:3` | Первые три столбца по порядку: позиции 0, 1, 2 |

| | PassengerId | Survived | Pclass |
|---|---|---|---|
| 0 | 1 | 0 | 3 |
| 1 | 2 | 1 | 1 |
| 2 | 3 | 1 | 3 |
| 3 | 4 | 1 | 1 |

**Что вернётся.** `DataFrame`. Проверка: `df.loc[0:4].shape` → `(5, 12)`, `df.iloc[0:4].shape` → `(4, 12)`.

| | `loc` | `iloc` |
|---|---|---|
| Выбирает по | Меткам индекса и названиям столбцов | Номерам позиций |
| Срез `0:4` | Включает 4 | Не включает 4 |
| Столбцы | `["Name", "Age"]` | `[3, 5]` или `0:3` |

В исходном `df` метки индекса совпадают с позициями (0…890), поэтому разница видна только в правой границе. После сортировки или фильтра метки и позиции расходятся: `loc[0]` и `iloc[0]` вернут разные строки, а если метки 0 в таблице больше нет — `loc[0]` упадёт с `KeyError: 0`. Пример (проверено отдельно): после фильтра 1-го класса из части 3 метки 0 нет, а `iloc[0]` вернёт первую оставшуюся строку — Cumings, Mrs. John Bradley.

**Типичные ошибки.**
- Названия в `iloc`: `df.iloc[0:4, ["Name"]]` → `IndexError: .iloc requires numeric indexers`.
- Номера столбцов в `loc`: `df.loc[0:4, 0:3]` → `TypeError: cannot do slice indexing...`.
- Круглые скобки: `df.loc(0:4)` — синтаксическая ошибка. У индексаторов только `[ ]`.

**Банковский пример.**

```python
clients.loc[0:2, ["client_id", "balance_kzt"]]
```

| | client_id | balance_kzt |
|---|---|---|
| 0 | 1001 | 250000.5 |
| 1 | 1002 | 4800000.0 |
| 2 | 1003 | 12000.0 |

```python
clients.iloc[0:2, 0:2]
```

| | client_id | segment |
|---|---|---|
| 0 | 1001 | mass |
| 1 | 1002 | premium |

Правило для рабочего кода: столбцы выбирать по названию (`loc`). Позиции ломаются, когда в выгрузке добавят или переставят поле.

### 2.6 Сортировка: sort_values

**Что это.** `sort_values()` — метод DataFrame: упорядочивает строки по значениям одного или нескольких столбцов.

**Зачем.** Найти самые крупные/мелкие значения, построить рейтинги, упорядочить внутри групп.

#### Выжимка для конспекта

1. `describe()`: `count` — известные значения, не строки. Для текста — `unique/top/freq`.
2. Описываю только измерения; среднее ID и категорий бессмысленно. Исключение — 0/1: среднее = доля.
3. Среднее ≫ медианы → хвост больших значений. Fare: 32.20 против 14.45.
4. `round(x, 2)` — функция Python; `.round(2)` — метод pandas.
5. Одни скобки → `Series`, двойные → `DataFrame`.
6. `loc` — метки, конец включён; `iloc` — позиции, конец не включён.
7. Цепочка читается слева направо, каждый шаг возвращает новый объект.
8. `sort_values` не меняет `df`; результат сохраняю в переменную. `NaN` по умолчанию в конце (`na_position`).

## Часть 3. Пропуски, частоты, фильтры

Порядок работы: сначала **посчитать** пропуски, потом решать, что с ними делать. Исходный `df` в этой части не меняется.

### 3.1 Подсчёт пропусков: isna и sum

**Что это.** `isna()` — метод DataFrame/Series: для каждой ячейки отвечает `True` (пусто) или `False` (заполнено). `sum()` складывает, считая `True` = 1, `False` = 0.

**Зачем.** Узнать, в каких столбцах и сколько данных отсутствует, до любых расчётов.

```python
missing_count = df.isna().sum()
missing_count.sort_values(ascending=False)
```

| Фрагмент | Разбор |
|---|---|
| `df.isna()` | Метод. Возвращает `DataFrame` того же размера `(891, 12)`, но из `True`/`False` |
| `.sum()` | Метод. Суммирует **по каждому столбцу** — получается число пропусков в столбце |
| `missing_count = ...` | Результат (`Series`) сохраняем в переменную, он понадобится в 3.2 |
| `.sort_values(ascending=False)` | У `Series` тоже есть `sort_values`; здесь столбец не указывают — сортируются сами значения |

**Что вернётся.** `Series`: индекс — названия столбцов, значения — количество пропусков (`int64`).

```text
Cabin          687
Age            177
Embarked         2
PassengerId      0
Name             0
Pclass           0
Survived         0
Sex              0
Parch            0
SibSp            0
Fare             0
Ticket           0
dtype: int64
```

Совпадает с `info()` из части 1: 891 − 714 = 177 для `Age`.

**Как найти записи с пропуском.**

```python
df.loc[df["Age"].isna(), ["Name", "Age", "Pclass"]].head()
```

`df["Age"].isna()` — `Series` из `True`/`False` по строкам. Передаём его в `loc` на место строк: остаются строки, где `True`. Такой `Series` называется **булевой маской** — подробно в 3.5.

| | Name | Age | Pclass |
|---|---|---|---|
| 5 | Moran, Mr. James | NaN | 3 |
| 17 | Williams, Mr. Charles Eugene | NaN | 2 |
| 19 | Masselmani, Mrs. Fatima | NaN | 3 |
| 26 | Emir, Mr. Farred Chehab | NaN | 3 |
| 28 | O'Dwyer, Miss. Ellen "Nellie" | NaN | 3 |

**Типичные ошибки.**
- Искать пропуски через сравнение: `(df["Age"] == np.nan).sum()` → `0`. `NaN` не равен ничему, даже себе (`np.nan == np.nan` → `False`). Только `isna()`.
- Считать `0` или пустую строку `""` пропуском. `isna()` их не видит — это заполненные значения.
- Путать `isna()` и `notna()`: второй — обратный, `True` там, где значение **есть**.

### 3.2 Таблица пропусков с процентами

**Что это.** Сводная таблица: количество и процент пропусков по столбцам, собранная через `pd.DataFrame(...)`.

**Зачем.** «177 пропусков» без знаменателя ничего не говорит. 177 из 891 — это почти 20%.

```python
missing_summary = pd.DataFrame({
    "missing_count": missing_count,
    "missing_percent": missing_count / len(df) * 100,
})
missing_summary.sort_values("missing_count", ascending=False).round(1)
```

| Фрагмент | Разбор |
|---|---|
| `pd.DataFrame(...)` | **Класс** pandas. Вызов класса создаёт новый объект — таблицу |
| `{ ... }` | **Словарь** Python (`dict`): пары `ключ: значение` через запятую |
| `"missing_count": missing_count` | Ключ — будущее название столбца, значение — `Series` с данными |
| `missing_count / len(df) * 100` | Арифметика над `Series`: каждое значение делится на 891 и умножается на 100. Без цикла — сразу для всех строк |
| Запятая после последней пары | Разрешена в Python, удобна при добавлении строк |
| `.sort_values("missing_count", ...)` | У DataFrame указываем, по какому столбцу сортировать |

**Что вернётся.** `DataFrame`: индекс — названия исходных столбцов (pandas выровнял два `Series` по общему индексу).

| | missing_count | missing_percent |
|---|---|---|
| Cabin | 687 | 77.1 |
| Age | 177 | 19.9 |
| Embarked | 2 | 0.2 |
| PassengerId | 0 | 0.0 |
| Name | 0 | 0.0 |
| Pclass | 0 | 0.0 |
| Survived | 0 | 0.0 |
| Sex | 0 | 0.0 |
| Parch | 0 | 0.0 |
| SibSp | 0 | 0.0 |
| Fare | 0 | 0.0 |
| Ticket | 0 | 0.0 |

Короче для одного столбца: `df["Age"].isna().mean()` → `0.1986...` — среднее из `True`/`False` и есть доля.

**Типичные ошибки.**
- Делить на неправильный знаменатель: `count()` вместо `len(df)` даёт число известных, а не всех.
- Путать долю (0.199) и процент (19.9). Указывайте, что именно в столбце.
- Забыть закрыть скобки словаря и функции: `{` закрывается `}`, `(` — `)`.

### 3.3 Работа с пропусками: dropna и fillna

**Что это.** `dropna()` — метод: убирает пропуски. `fillna(значение)` — метод: подставляет значение вместо пропусков. Оба возвращают **новый** объект.

**Зачем.** Часть расчётов требует данных без пропусков. Важно делать это в отдельной переменной и осознанно.

```python
known_ages = df["Age"].dropna()
print("Всего пассажиров:", len(df))
print("Возраст известен:", known_ages.count())
```

| Фрагмент | Разбор |
|---|---|
| `df["Age"].dropna()` | Для `Series`: убрать пропущенные значения. Результат — `Series` из 714 значений |
| `len(df)` | Функция Python: строк в таблице |
| `.count()` | Метод pandas: число **известных** значений |

```text
Всего пассажиров: 891
Возраст известен: 714
```

Почему не `df.dropna()` для всей таблицы: он удаляет строку, если пусто **хоть в одном** столбце. Результат — `(183, 12)`: из-за `Cabin` пропадает 79% пассажиров, хотя для подсчёта по классу каюта не нужна.

```python
age_filled_example = df["Age"].fillna(df["Age"].median())
print("Пропусков в примере:", age_filled_example.isna().sum())
print("Пропусков в исходном Age:", df["Age"].isna().sum())
```

| Фрагмент | Разбор |
|---|---|
| `df["Age"].median()` | Сначала считается медиана — 28.0 |
| `.fillna(28.0)` | Каждый `NaN` заменяется на 28.0 |
| Новая переменная | `df["Age"]` остаётся как был |

```text
Пропусков в примере: 0
Пропусков в исходном Age: 177
```

**Как заполнение искажает данные** (посчитано отдельно):

| | Исходный `Age` | После `fillna(median)` |
|---|---|---|
| Пассажиров с возрастом ровно 28 | 25 | 202 |
| Среднее | 29.70 | 29.36 |
| Стандартное отклонение | 14.53 | 13.02 |

177 одинаковых значений создают пик на 28 и уменьшают разброс. Заполнение — технический приём, а не восстановление настоящего возраста. Заполнить нулём ещё хуже: 177 «новорождённых».

**Что вернётся.** `dropna()` для `Series` — `Series` короче исходного; `fillna()` — `Series` той же длины.

**Типичные ошибки.**
- `df.dropna()` на всю таблицу без размышлений → потеря 708 строк.
- Ждать, что `df["Age"].fillna(...)` изменит `df`. Без присваивания результат теряется.
- Заполнять, а потом описывать заполненную колонку как «возраст пассажиров».

### 3.4 Частоты и доли: value_counts

**Что это.** `value_counts()` — метод `Series`: считает, сколько раз встречается каждое значение.

**Зачем.** Основной инструмент для категорий: сколько в каждом классе, порту, сегменте.

```python
class_counts = df["Pclass"].value_counts().sort_index()
class_counts
```

| Фрагмент | Разбор |
|---|---|
| `.value_counts()` | Подсчёт. По умолчанию сортирует по убыванию частоты: `3, 1, 2` |
| `.sort_index()` | Метод: сортировать по индексу — `1, 2, 3`. Для упорядоченных категорий так читается лучше |

**Что вернётся.** `Series`: индекс — значения категории, значения — количества.

```text
Pclass
1    216
2    184
3    491
Name: count, dtype: int64
```

Сверху `Pclass` — имя индекса (из какого столбца категории), `Name: count` — имя самих значений.

**Доли:**

```python
(df["Sex"].value_counts(normalize=True) * 100).round(1)
```

| Фрагмент | Разбор |
|---|---|
| `normalize=True` | Именованный аргумент: вместо количества — доля от 0 до 1 |
| `( ... ) * 100` | Скобки нужны, чтобы умножить результат, а потом вызвать `.round(1)` у всего выражения |

```text
Sex
male      64.8
female    35.2
Name: proportion, dtype: float64
```

**Пропуски в частотах:**

```python
df["Embarked"].value_counts(dropna=False)
```

`dropna=False` — показать `NaN` отдельной строкой. По умолчанию (`True`) пропуски молча исключаются.

```text

C      168
Q       77

```

От этого аргумента зависит знаменатель долей (посчитано отдельно):

|---|---|---|
| S | 72.4% от 889 | 72.3% от 891 |
| C | 18.9% | 18.9% |
| Q | 8.7% | 8.6% |
| NaN | — | 0.2% |

**Доля для 0/1 через mean:**

```python
print("Количество по исходам:")
display(df["Survived"].value_counts().sort_index())
print("Доля выживших в этом наборе, %:", round(df["Survived"].mean() * 100, 1))
```

`display(...)` нужен, потому что `value_counts()` стоит не в последней строке ячейки (см. часть 1). `mean()` для столбца из 0 и 1 = сумма единиц / число строк = доля единиц.

```text

Survived
0    549
1    342
Name: count, dtype: int64
Доля выживших в этом наборе, %: 38.4
```

Проверка: 342 / 891 = 0.384.

**Типичные ошибки.**
- Забыть `dropna=False` и не увидеть, что у части записей категория неизвестна.
- Называть процент без знаменателя: «72% из Southampton» — из всех или из известных?
- Округлить до умножения: `value_counts(normalize=True).round(1) * 100` → `male 60.0`, `female 40.0` вместо 64.8 и 35.2. Доля 0.648 сначала стала 0.6. Поэтому сначала `* 100` в скобках, потом `.round(1)`.

**Банковский пример.** Структура клиентской базы:

```python

(clients["segment"].value_counts(normalize=True) * 100).round(1)
```

```text
premium    1
sme        1
```

### 3.5 Булева маска

**Что это.** Сравнение столбца со значением даёт `Series` из `True`/`False` — по одному на строку. Это и есть маска. Передав её в `loc`, оставляем строки с `True`.

**Зачем.** Фильтрация: «только 1-й класс», «только клиенты сегмента premium».

```python
is_first_class = df["Pclass"] == 1
is_first_class.head()
```

| Фрагмент | Разбор |
|---|---|
| `==` | Оператор Python «равно». Не путать с `=` — присваивание |
| `df["Pclass"] == 1` | Сравнение применяется к каждому значению столбца сразу |
| `is_first_class = ...` | Маску сохраняем в переменную. Имя с `is_` подсказывает, что внутри `True`/`False` |

```text
0    False
1     True
2    False
3     True
4    False
Name: Pclass, dtype: bool
```

`dtype: bool` — логический тип.

```python
first_class = df.loc[is_first_class, ["Name", "Age", "Fare"]]
print("Пассажиров первого класса:", len(first_class))
first_class.head()
```

`df.loc[маска, столбцы]` — на месте строк стоит маска.

```text
Пассажиров первого класса: 216
```

| | Name | Age | Fare |
|---|---|---|---|
| 1 | Cumings, Mrs. John Bradley (Florence Briggs Th... | 38.0 | 71.2833 |

Индекс с пропусками (1, 3, 6, 11, …) — строки сохранили исходные метки. 216 совпадает с `value_counts` из 3.4.

**Что вернётся.** Маска — `Series` типа `bool` длиной 891. Фильтр — `DataFrame` только с подходящими строками.

Операторы сравнения: `==` равно, `!=` не равно, `>`, `<`, `>=`, `<=`.

**Типичные ошибки.**
- `df["Pclass"] = 1` вместо `==` — **перезапишет** весь столбец единицами.

### 3.6 Несколько условий: &, |, ~, isin

**Что это.** Операторы, объединяющие маски поэлементно: `&` — И, `|` — ИЛИ, `~` — НЕ. `isin()` — метод: «значение входит в список».

**Зачем.** Реальные фильтры почти всегда составные: сегмент **и** город, сумма **или** страна.

```python
children = df.loc[df["Age"].notna() & (df["Age"] < 18)]
children[["Name", "Age", "Pclass"]].head()
```

| Фрагмент | Разбор |
|---|---|
| `df["Age"].notna()` | Маска «возраст известен» |
| `&` | И: `True` только там, где обе маски `True` |
| `(df["Age"] < 18)` | Скобки **обязательны** вокруг сравнения |
| `df.loc[маска]` | Без столбцов после запятой — берутся все столбцы |

| | Name | Age | Pclass |
|---|---|---|---|
| 7 | Palsson, Master. Gosta Leonard | 2.0 | 3 |
| 9 | Nasser, Mrs. Nicholas (Adele Achem) | 14.0 | 2 |
| 10 | Sandstrom, Miss. Marguerite Rut | 4.0 | 3 |
| 14 | Vestrom, Miss. Hulda Amanda Adolfina | 14.0 | 3 |
| 16 | Rice, Master. Eugene | 2.0 | 3 |

Детей с известным возрастом — 113.

**Как сравнения ведут себя с NaN** (посчитано отдельно). Сравнение `NaN < 18` даёт `False`, поэтому:

| Фильтр | Строк | Пояснение |
|---|---|---|
| `df["Age"].notna() & (df["Age"] < 18)` | 113 | Явно: известен и меньше 18 |
| `df["Age"] < 18` | 113 | То же: `NaN` и так не прошёл |
| `df["Age"] >= 18` | 601 | Взрослые с известным возрастом |
| `~(df["Age"] >= 18)` | 290 | **Ловушка**: 113 детей + 177 неизвестных |

`notna()` в коде ноутбука не меняет результат, но делает намерение явным и защищает от ловушки с `~`: «не взрослый» ≠ «ребёнок».

```python
adult_women = df.loc[(df["Sex"] == "female") & (df["Age"] >= 18)]
print("Совершеннолетних женщин с известным возрастом:", len(adult_women))
adult_women[["Name", "Sex", "Age"]].head()
```


|---|---|---|---|
| 1 | Cumings, Mrs. John Bradley (Florence Briggs Th... | female | 38.0 |

| 3 | Futrelle, Mrs. Jacques Heath (Lily May Peel) | female | 35.0 |
| 8 | Johnson, Mrs. Oscar W (Elisabeth Vilhelmina Berg) | female | 27.0 |
| 11 | Bonnell, Miss. Elizabeth | female | 58.0 |

**isin:**

```python

```

`isin(["C", "Q"])` — метод `Series`, аргумент — список. Равносильно `(df["Embarked"] == "C") | (df["Embarked"] == "Q")`, но короче. Строк — 245 (168 + 77).

| | Name | Embarked |
|---|---|---|
| 1 | Cumings, Mrs. John Bradley (Florence Briggs Th... | C |
| 5 | Moran, Mr. James | Q |
| 9 | Nasser, Mrs. Nicholas (Adele Achem) | C |
| 16 | Rice, Master. Eugene | Q |
| 19 | Masselmani, Mrs. Fatima | C |

**Что вернётся.** Комбинация масок — снова маска (`Series` типа `bool`); `loc` с ней — `DataFrame`.

| Оператор | Значение | Python-аналог для одиночных значений |
|---|---|---|
| `&` | И | `and` |
| `\|` | ИЛИ | `or` |
| `~` | НЕ | `not` |

**Типичные ошибки.**
- `and`/`or` вместо `&`/`|` → `ValueError: The truth value of a Series is ambiguous`. `and` работает с одним `True`/`False`, а маска — это 891 значение.
- Без скобок: `df["Sex"] == "female" & df["Age"] >= 18` → `TypeError: Cannot perform 'rand_' ...`. `&` выполняется раньше `==` и `>=`, поэтому каждое сравнение — в скобки.
- `~` по столбцу с пропусками захватывает `NaN` (ловушка из таблицы выше).

**Банковский пример.** Клиенты mass с балансом меньше 100 000 и клиенты из двух городов:

```python
clients.loc[(clients["segment"] == "mass") & (clients["balance_kzt"] < 100000), ["client_id", "balance_kzt"]]
```

| | client_id | balance_kzt |
|---|---|---|
| 2 | 1003 | 12000.0 |

```python
clients.loc[clients["city"].isin(["Almaty", "Astana"]), ["client_id", "city"]]
```

| | client_id | city |
|---|---|---|
| 0 | 1001 | Almaty |
| 1 | 1002 | Astana |
| 3 | 1004 | Almaty |

Ловушка с `~` на деньгах:

```python
clients.loc[~(clients["balance_kzt"] >= 100000), ["client_id", "balance_kzt"]]
```

| | client_id | balance_kzt |
|---|---|---|
| 2 | 1003 | 12000.0 |
| 4 | 1005 | NaN |

Клиент 1005 с неизвестным балансом попал в «малые балансы». Если по такому списку запустить, например, предложение о пополнении, он получит его ошибочно.

1. Сначала считаю пропуски (`isna().sum()`), потом решаю, что с ними делать.
2. `NaN` ≠ 0 и `NaN` ≠ `NaN`; искать только через `isna()`.
3. Доля всегда со знаменателем: все строки (`len(df)`) или известные (`count()`).
4. `df.dropna()` на всю таблицу удаляет строки из-за любого столбца — Titanic: 891 → 183.
5. `fillna(median)` меняет распределение: делаю в отдельной переменной.

8. `&`, `|`, `~` вместо `and`, `or`, `not`; каждое условие в скобках.
9. `~(условие)` захватывает `NaN` — «не взрослый» ≠ «ребёнок».

## Часть 4. Новые признаки и группировки

### 4.1 Копия таблицы: copy

**Что это.** `copy()` — метод DataFrame: создаёт независимую копию таблицы.

**Зачем.** Учебные и производные столбцы добавляем в копию, а `df` остаётся таким, каким загрузили. Так всегда можно сверить результат с исходником.

```python
analysis_df = df.copy()
```

| Фрагмент | Разбор |
|---|---|
| `df.copy()` | Метод. Возвращает новый `DataFrame` с теми же данными |
| `analysis_df = ...` | Новая переменная указывает на копию |

Почему не просто `analysis_df = df` (проверено отдельно):

| Код | Столбцов в `df` после добавления столбца в `analysis_df` |
|---|---|
| `analysis_df = df` | 13 — `df` изменился |
| `analysis_df = df.copy()` | 12 — `df` не тронут |

Знак `=` в Python не копирует объект, а даёт ему **второе имя**. `analysis_df = df` — две переменные на одну и ту же таблицу. Проверка: `analysis_df is df` → `True` без `copy()` и `False` с ним (`is` — оператор Python «это один и тот же объект?»).

**Типичные ошибки.**
- `new = df` в расчёте, что это копия → изменения попадают в исходник.
- Добавить столбец в копию, а потом искать его в `df`: `df.FamilySize` → `AttributeError: 'DataFrame' object has no attribute 'FamilySize'`.
- Делать копию на каждый шаг без нужды: для фильтров и `head()` копия не нужна — они и так возвращают новый объект.

---

### 4.2 Новый числовой столбец

**Что это.** Присваивание `df["новое_имя"] = выражение` создаёт столбец. Выражение считается для всех строк сразу.

**Зачем.** Получить признак, которого нет в исходных данных, но который выводится из других полей.

```python
analysis_df["FamilySize"] = analysis_df["SibSp"] + analysis_df["Parch"] + 1
analysis_df[["SibSp", "Parch", "FamilySize"]].head()
```

| Фрагмент | Разбор |
|---|---|
| `analysis_df["FamilySize"] = ...` | Слева квадратные скобки с новым именем — создать столбец. Если такой уже есть, он **перезапишется** |
| `analysis_df["SibSp"] + analysis_df["Parch"]` | Сложение двух `Series` построчно: значение строки 0 со значением строки 0 и т.д. |
| `+ 1` | Число прибавляется к каждому значению — сам пассажир |

**Что вернётся.** Присваивание ничего не выводит; в `analysis_df` становится на один столбец больше.

| | SibSp | Parch | FamilySize |
|---|---|---|---|
| 0 | 1 | 0 | 2 |
| 1 | 1 | 0 | 2 |
| 2 | 0 | 0 | 1 |
| 3 | 1 | 0 | 2 |
| 4 | 0 | 0 | 1 |

Распределение нового признака (посчитано отдельно, `value_counts().sort_index()`):

| FamilySize | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 11 |
|---|---|---|---|---|---|---|---|---|---|
| Пассажиров | 537 | 161 | 102 | 29 | 15 | 22 | 12 | 6 | 7 |

Ограничение смысла: это «пассажир + родственники по полям `SibSp`/`Parch`», а не доказанный размер семьи. Кузены, друзья, прислуга сюда не попадают.

**Типичные ошибки.**
- Создать столбец через точку: `analysis_df.FamilySize = ...` — pandas не создаст столбец (выдаст предупреждение). Только через `["..."]`.
- Случайно перезаписать существующий столбец, выбрав занятое имя.
- Складывать столбцы с `NaN`: результат в этой строке тоже `NaN`. Здесь не проблема — у `SibSp` и `Parch` пропусков нет.

---

### 4.3 Новый логический столбец

**Что это.** Столбец, куда записана маска — результат сравнения, `True`/`False` для каждой строки.

**Зачем.** Флаг удобно фильтровать, считать (`value_counts`, `mean` = доля) и группировать.

```python
analysis_df["IsAlone"] = analysis_df["FamilySize"] == 1
analysis_df["IsAlone"].value_counts()
```

Справа маска из части 3: `== 1` применяется ко всем строкам. Слева — новый столбец. Сначала выполняется правая часть, потом присваивание.

**Что вернётся.** Столбец типа `bool`. `value_counts()`:

```text
IsAlone
True     537
False    354
Name: count, dtype: int64
```

537 совпадает с `FamilySize == 1` из таблицы выше.

**Типичные ошибки.**
- Перепутать `=` и `==` в правой части.
- Считать, что флаг «знает» о пропусках. Сравнение с `NaN` даёт `False`, и неизвестное значение молча станет «нет» (см. банковский пример).
- Называть флаг расплывчато. `IsAlone` ниже может прочитаться как «путешествовал совсем один», хотя смысл — «без родственников в полях `SibSp`/`Parch`».

**Банковский пример.** Флаги на клиентах (на копии):

```python
b = clients.copy()
b["has_txn"] = b["last_txn_date"].notna()
b["is_vip"] = b["balance_kzt"] >= 1000000
b[["client_id", "balance_kzt", "has_txn", "is_vip"]]
```

| | client_id | balance_kzt | has_txn | is_vip |
|---|---|---|---|---|
| 0 | 1001 | 250000.50 | True | False |
| 1 | 1002 | 4800000.00 | True | True |
| 2 | 1003 | 12000.00 | False | False |
| 3 | 1004 | 950000.75 | True | False |
| 4 | 1005 | NaN | True | False |

Клиент 1005: баланс неизвестен, а `is_vip` = `False`. Флаг утверждает больше, чем знают данные.

### 4.4 Группировка: groupby, size, count

**Что это.** `groupby("столбец")` — метод DataFrame: делит строки на группы по значению столбца. Потом к каждой группе применяют расчёт, и результаты собираются в одну таблицу.

```text
df ──groupby("Pclass")──► группа 1 (216 строк) ──► расчёт ──┐
                          группа 2 (184 строки) ──► расчёт ──┼──► результат: одна строка на группу
                          группа 3 (491 строка) ──► расчёт ──┘
```

**Зачем.** Сравнить группы одной командой вместо трёх фильтров.

```python
class_sizes = df.groupby("Pclass").size()
class_age_counts = df.groupby("Pclass")["Age"].count()
pd.DataFrame({"passengers": class_sizes, "known_ages": class_age_counts})
```

| Фрагмент | Разбор |
|---|---|
| `df.groupby("Pclass")` | Метод. Сам по себе ничего не считает — возвращает объект-группировку (`DataFrameGroupBy`) |
| `.size()` | Метод группировки: **число строк** в каждой группе |
| `["Age"]` | Из группировки выбираем один столбец |
| `.count()` | Число **заполненных** значений `Age` в каждой группе |
| `pd.DataFrame({...})` | Собираем два `Series` в таблицу, как в части 3 |

**Что вернётся.** `size()` и `count()` по одному столбцу → `Series`, индекс — значения группы.

| Pclass | passengers | known_ages |
|---|---|---|
| 1 | 216 | 186 |
| 2 | 184 | 173 |
| 3 | 491 | 355 |

Пропуски возраста распределены неравномерно: в 1-м классе возраст неизвестен у 14%, в 3-м — у 28%.

```python
df.groupby("Pclass")["Age"].mean().round(1)
```

```text
Pclass
1    38.2
2    29.9
3    25.1
Name: Age, dtype: float64
```

Среднее в каждой группе считается только по известным значениям — по 186, 173 и 355 пассажирам соответственно.

| | `size()` | `count()` |
|---|---|---|
| Считает | Строки в группе | Заполненные значения столбца |
| `NaN` | Учитывает | Пропускает |
| Нужен столбец | Нет | Да |

**Типичные ошибки.**
- Использовать `count()` как размер группы → для `Age` в 3-м классе получите 355 вместо 491.
- Ждать результат от `df.groupby("Pclass")` без метода расчёта — вернётся объект группировки, а не числа.
- Группировать по столбцу с пропусками и потерять группу: `groupby("Embarked").size()` покажет C, Q, S, но **не** 2 записи с `NaN`. Нужен `groupby("Embarked", dropna=False)`.

### 4.5 Несколько показателей: agg

**Что это.** `agg([...])` — метод группировки: применяет к каждой группе список расчётов сразу.

**Зачем.** Собрать в одной таблице размер группы, центр и границы.

```python
fare_by_class = df.groupby("Pclass")["Fare"].agg(["count", "mean", "median", "min", "max"])
fare_by_class.round(2)
```

| Фрагмент | Разбор |
|---|---|
| `["Fare"]` | Считаем по стоимости |
| `.agg([...])` | Аргумент — список **названий** расчётов строками: `"count"`, `"mean"`, ... |

**Что вернётся.** `DataFrame`: строки — группы, столбцы — показатели.

| Pclass | count | mean | median | min | max |
|---|---|---|---|---|---|
| 1 | 216 | 84.15 | 60.29 | 0.0 | 512.33 |
| 2 | 184 | 20.66 | 14.25 | 0.0 | 73.50 |
| 3 | 491 | 13.68 | 8.05 | 0.0 | 69.55 |

В каждом классе среднее выше медианы, а нулевая стоимость встречается во всех трёх.

**Доля внутри группы и новый столбец в результате:**

```python
survival_by_class = df.groupby("Pclass")["Survived"].agg(["count", "mean"])
survival_by_class["survived_percent"] = survival_by_class["mean"] * 100
survival_by_class[["count", "survived_percent"]].round(1)
```

| Строка | Разбор |
|---|---|
| 1 | `mean` от 0/1 в группе — доля выживших в этой группе. Результат — `DataFrame` со столбцами `count`, `mean` |
| 2 | Результат `agg` — обычный DataFrame, в него можно добавить столбец так же, как в 4.2 |
| 3 | Показываем размер группы и процент |

| Pclass | count | survived_percent |
|---|---|---|
| 1 | 216 | 63.0 |
| 2 | 184 | 47.3 |
| 3 | 491 | 24.2 |

Знаменатель каждого процента — `count` своей группы. Это описание набора записей. Разница между классами сама по себе не доказывает, что класс — причина: классы различаются ещё и по полу, возрасту, расположению кают.

**Группировка по двум столбцам** (посчитано отдельно):

```python
df.groupby(["Sex", "Pclass"])["Survived"].mean().round(3)
```

```text
Sex     Pclass
female  1         0.968
        2         0.921
        3         0.500
male    1         0.369
        2         0.157
        3         0.135
Name: Survived, dtype: float64
```

Список столбцов в `groupby` → группы по сочетаниям; индекс становится двухуровневым.

**Типичные ошибки.**
- Считать `mean` по тексту: `groupby("Pclass")["Name"].mean()` → `TypeError: dtype 'str' does not support operation 'mean'`.
- Показывать процент без `count`: 100% выживших в группе из 2 человек ничего не значит.
- Писать `agg(count, mean)` без кавычек и списка → `NameError`. Названия расчётов — строки в списке.

**Банковский пример.** Баланс по сегментам:

```python
b.groupby("segment")["balance_kzt"].agg(["count", "median", "max"])
```

| segment | count | median | max |
|---|---|---|---|
| mass | 2 | 131000.25 | 250000.50 |
| premium | 1 | 4800000.00 | 4800000.00 |
| sme | 1 | 950000.75 | 950000.75 |

В `mass` три клиента (`b.groupby("segment").size()` → 3), но `count` = 2: у 1005 баланс неизвестен. Медиана mass посчитана по двум клиентам из трёх.

### 4.6 Таблица сопряжённости: crosstab

**Что это.** `pd.crosstab(строки, столбцы)` — функция pandas: считает, сколько записей приходится на каждое сочетание двух категорий.

**Зачем.** Увидеть состав групп: сколько женщин и мужчин в каждом классе.

```python
sex_class_counts = pd.crosstab(df["Sex"], df["Pclass"])
sex_class_counts
```

| Фрагмент | Разбор |
|---|---|
| `pd.crosstab` | **Функция** pandas (вызывается от `pd`, а не от `df`) |
| `df["Sex"]` | Первый аргумент — категории для строк |
| `df["Pclass"]` | Второй — категории для столбцов |

**Что вернётся.** `DataFrame`: на пересечении — количество.

| Sex \ Pclass | 1 | 2 | 3 |
|---|---|---|---|
| female | 94 | 76 | 144 |
| male | 122 | 108 | 347 |

Итоги по строкам и столбцам добавляет `margins=True` (посчитано отдельно): женщин 314, мужчин 577, всего 891.

**Доли:**

```python
(pd.crosstab(df["Sex"], df["Pclass"], normalize="index") * 100).round(1)
```

`normalize="index"` — каждую **строку** делить на её сумму: строка даёт 100%.

| Sex \ Pclass | 1 | 2 | 3 |
|---|---|---|---|
| female | 29.9 | 24.2 | 45.9 |
| male | 21.1 | 18.7 | 60.1 |

Читается: «из всех женщин 29.9% ехали в 1-м классе».

Тот же расчёт с `normalize="columns"` (посчитано отдельно) отвечает на другой вопрос — «из пассажиров класса сколько женщин»:

| Sex \ Pclass | 1 | 2 | 3 |
|---|---|---|---|
| female | 43.5 | 41.3 | 29.3 |
| male | 56.5 | 58.7 | 70.7 |

| `normalize=` | Знаменатель | Вопрос |
|---|---|---|
| `"index"` | Сумма строки | Как распределена строка-категория по столбцам |
| `"columns"` | Сумма столбца | Каков состав каждого столбца |
| `True` / `"all"` | Все записи | Доля сочетания от всех |

**Типичные ошибки.**
- Вызывать как метод: `df.crosstab(...)` → `AttributeError`. Это функция `pd.crosstab`.
- Перепутать `"index"` и `"columns"` и ответить не на тот вопрос: 29.9% и 43.5% — обе цифры про «женщин в 1-м классе», но с разными знаменателями.
- Забыть, что `crosstab` по умолчанию исключает `NaN` в категориях.

**Банковский пример.** Сегменты по городам:

```python
pd.crosstab(b["segment"], b["city"])
```

| segment \ city | Almaty | Astana | Atyrau | Shymkent |
|---|---|---|---|---|
| mass | 1 | 0 | 1 | 1 |
| premium | 0 | 1 | 0 | 0 |
| sme | 1 | 0 | 0 | 0 |

На реальной базе это первый шаг перед планированием кампании по регионам: где сколько клиентов каждого сегмента.

### Итоги части 4

#### Шпаргалка

| Запись | Что делает | Вернёт |
|---|---|---|
| `new = df.copy()` | Независимая копия | `DataFrame` |
| `new = df` | Второе имя для той же таблицы, **не** копия | — |
| `a is b` | Один и тот же объект? | `bool` |
| `df["C"] = df["A"] + df["B"]` | Новый столбец построчно | — |
| `df["Flag"] = df["A"] == 1` | Логический столбец | — |
| `df.groupby("A")` | Объект-группировка, сам не считает | `DataFrameGroupBy` |
| `df.groupby("A").size()` | Строк в группе | `Series` |
| `df.groupby("A")["B"].count()` | Заполненных `B` в группе | `Series` |
| `df.groupby("A")["B"].mean()` | Среднее `B` в группе | `Series` |
| `df.groupby("A")["B"].agg(["count", "mean"])` | Несколько показателей | `DataFrame` |
| `df.groupby(["A", "B"])["C"].mean()` | Группы по сочетаниям | `Series` с двухуровневым индексом |
| `groupby("A", dropna=False)` | Сохранить группу `NaN` | — |
| `pd.crosstab(df["A"], df["B"])` | Количество сочетаний | `DataFrame` |
| `crosstab(..., normalize="index")` | Доли по строкам | `DataFrame` |
| `crosstab(..., margins=True)` | Добавить итоги `All` | `DataFrame` |

#### Выжимка для конспекта

1. Новые столбцы — в копию `df.copy()`; `new = df` не копирует.
2. `df["new"] = выражение` — считается сразу для всех строк; существующее имя перезапишется.
3. Флаг из сравнения: `NaN` в сравнении → `False`, неизвестное превращается в «нет».
4. `groupby` = разделить → посчитать → собрать. Без метода расчёта ничего не считает.
5. `size()` — строки, `count()` — заполненные значения. Для `Age` разница большая.
6. `agg([...])` — несколько показателей; результат — обычный DataFrame, можно добавлять столбцы.
7. Процент группы всегда рядом с её размером. Разница групп ≠ причина.
8. `crosstab`: `normalize="index"` — состав строки, `"columns"` — состав столбца.

#### Упражнения

1. На копии `df` создайте столбец `IsChild` — `True` для пассажиров младше 18 лет. Сколько получилось `True`? Объясните, почему число `False` не равно числу взрослых (601).
2. Сгруппируйте по `Embarked` с `dropna=False` и посчитайте для `Age` три показателя: `size`, `count`, `median`. В каком порту доля неизвестных возрастов выше всего?
3. Постройте `pd.crosstab` для `Pclass` и `Survived` с `normalize="index"`. Сформулируйте одно предложение-наблюдение с указанием знаменателя и одно предложение о том, чего из этой таблицы вывести **нельзя**.

#### Где пригодится в AI Engineering

- Evaluation: качество ответов LLM сравнивают по срезам — `groupby` по типу вопроса, языку, версии промпта с `agg(["count", "mean"])`. Средняя оценка без `count` по срезу вводит в заблуждение так же, как здесь.
- Feature-флаги в логах агентов: столбцы вида `used_tool`, `has_retrieval_hits` из сравнений, затем `crosstab` «был ли поиск × ответ корректен».

## Часть 5. NumPy и графики

### 5.1 Массив NumPy: np.array

**Что это.** `np.array(...)` — функция NumPy, создаёт **массив** (`ndarray`): набор значений одного типа. У массива нет названий столбцов и индекса pandas — только позиции.

**Зачем.** NumPy — основа pandas: внутри столбцов лежат такие массивы. Он считает над всеми элементами сразу и быстро.

```python
numbers = np.array([10, 20, 30, 40], dtype=float)
print(numbers)
print("Форма:", numbers.shape, "Размерность:", numbers.ndim, "Тип:", numbers.dtype)
```

| Фрагмент | Разбор |
|---|---|
| `np.array` | `np` — NumPy (из `import numpy as np`), `array` — функция |
| `[10, 20, 30, 40]` | Список Python — из него строится массив |
| `dtype=float` | Именованный аргумент: хранить как дробные. `float` — встроенный тип Python. Без него было бы `int64` |
| `.shape` | Атрибут: размер по каждому измерению — кортеж `(4,)` |
| `.ndim` | Атрибут: число измерений. `1` — одномерный (как столбец) |
| `.dtype` | Атрибут: тип элементов |

**Что вернётся.** Объект `numpy.ndarray`.

```text
[10. 20. 30. 40.]
Форма: (4,) Размерность: 1 Тип: float64
```

Точка после числа (`10.`) — так NumPy печатает дробные. Запятых между элементами нет, в отличие от списка.

`(4,)` — кортеж из одного элемента: запятая обязательна, иначе Python прочитает `(4)` как просто число в скобках.

**Типичные ошибки.**
- `np.array(10, 20, 30)` без квадратных скобок → ошибка. Значения передаются **одним** аргументом — списком.
- Смешать типы: `np.array([1, "a"])` → тип `<U21` (строки), числа превратились в текст.
- Путать `shape` массива `(4,)` и таблицы `(891, 12)`.

---

### 5.2 Индексация, срезы, маска в массиве

**Что это.** Те же правила, что у списков Python: номер в `[ ]`, срез `начало:конец`, плюс маска как в pandas.

**Зачем.** Достать нужные элементы без цикла.

```python
print("Первый элемент:", numbers[0])
print("Первые три:", numbers[:3])
print("Больше 20:", numbers[numbers > 20])
```

| Фрагмент | Разбор |
|---|---|
| `numbers[0]` | Элемент на позиции 0 — одно число |
| `numbers[:3]` | Срез: начало не указано = с 0; позиции 0, 1, 2. Правая граница не включается |
| `numbers > 20` | Маска-массив: `[False False True True]` |
| `numbers[маска]` | Оставить элементы с `True` |

```text
Первый элемент: 10.0
Первые три: [10. 20. 30.]
Больше 20: [30. 40.]
```

Отрицательный индекс считает с конца: `numbers[-1]` → `40.0`.

**Что вернётся.** Один индекс — одно число; срез и маска — новый массив.

**Типичные ошибки.**
- Выйти за границы: `numbers[4]` → `IndexError: index 4 is out of bounds for axis 0 with size 4`. Позиции 0…3.
- Ждать `loc`/`iloc` у массива — их нет, только `[ ]`.
- Ожидать, что срез `[:3]` включит позицию 3.

---

### 5.3 Агрегаты и векторные операции

**Что это.** Агрегат — функция, сворачивающая массив в одно число (`np.sum`, `np.mean`). Векторная операция — арифметика, применяемая к каждому элементу.

**Зачем.** Считать без циклов `for`: короче и быстрее.

```python
print("Сумма:", np.sum(numbers))
print("Среднее:", np.mean(numbers))
print("Медиана:", np.median(numbers))
print("Минимум / максимум:", np.min(numbers), np.max(numbers))
```

Все — **функции** NumPy: вызываются от `np`, массив передаётся аргументом. Сравните с pandas, где это методы: `df["Age"].mean()`.

```text
Сумма: 100.0
Среднее: 25.0
Медиана: 25.0
Минимум / максимум: 10.0 40.0
```

```python
print("Плюс 5:", numbers + 5)
print("Удвоение:", numbers * 2)
print("Исходный массив:", numbers)
```

```text
Плюс 5: [15. 25. 35. 45.]
Удвоение: [20. 40. 60. 80.]
Исходный массив: [10. 20. 30. 40.]
```

Операция возвращает новый массив; `numbers` не изменился.

**Массив и список ведут себя по-разному** (проверено отдельно):

| Операция | Список Python `[10, 20, 30]` | Массив NumPy |
|---|---|---|
| `+ 5` | `TypeError: can only concatenate list (not "int") to list` | Прибавит 5 к каждому |
| `* 2` | `[10, 20, 30, 10, 20, 30]` — повтор списка | Умножит каждый элемент |

**Типичные ошибки.**
- Делать арифметику над списком, думая, что это массив.
- Ждать, что `numbers + 5` изменит `numbers`. Нужно присвоить: `numbers = numbers + 5`.
- Путать функцию и метод: `np.mean(numbers)` и `numbers.mean()` работают оба, но `np.mean` — функция NumPy, `.mean()` — метод массива.

**Банковский пример.** Суммы транзакций в тенге → в доллары по курсу (курс условный):

```python
amounts = np.array([15000, 250000, np.nan, 4800, 1200000], dtype=float)
rate = 475.0
np.round(amounts / rate, 2)
```

```text
[  31.58  526.32     nan   10.11 2526.32]
```

Одна строка пересчитывает все суммы. `np.nan` — пропуск в NumPy (тот же `NaN`); после деления он остаётся `nan`.

### 5.4 Из pandas в NumPy и пропуски nan

**Что это.** `to_numpy()` — метод `Series`: возвращает значения столбца как массив NumPy, без индекса и имени.

**Зачем.** Многие библиотеки (в том числе ML) принимают именно массивы. И важно знать, как NumPy обращается с пропусками — иначе, чем pandas.

```python
ages_array = df["Age"].to_numpy()
print("Форма массива:", ages_array.shape)
print("Первые 10 возрастов:", ages_array[:10])
```

```text
Форма массива: (891,)
Первые 10 возрастов: [22. 38. 26. 35. 35. nan 54.  2. 27. 14.]
```

891 элемент — пропуски никуда не делись, на позиции 5 `nan`.

```python
print("Обычное среднее NumPy:", np.mean(ages_array))
print("Количество nan:", np.isnan(ages_array).sum())
```

| Фрагмент | Разбор |
|---|---|
| `np.mean(ages_array)` | Обычное среднее. Если есть хоть один `nan`, результат `nan` |
| `np.isnan(ages_array)` | Функция NumPy: маска-массив, `True` на месте `nan`. Аналог `isna()` в pandas |
| `.sum()` | Метод массива: число `True` |

```text
Обычное среднее NumPy: nan
Количество nan: 177
```

**nan-функции** пропускают неизвестные значения явно:

```python
print("Средний возраст:", round(np.nanmean(ages_array), 2))
print("Медианный возраст:", np.nanmedian(ages_array))
print("Среднее pandas:", round(df["Age"].mean(), 2))
```

```text
Средний возраст: 29.7
Медианный возраст: 28.0
Среднее pandas: 29.7
```

**Убрать nan маской:**

```python
valid_ages_array = ages_array[~np.isnan(ages_array)]
print("Известных возрастов:", valid_ages_array.size)
print("25%, 50%, 75%:", np.quantile(valid_ages_array, [0.25, 0.5, 0.75]))
```

| Фрагмент | Разбор |
|---|---|
| `~np.isnan(...)` | `~` переворачивает маску: `True` там, где значение **есть** |
| `ages_array[...]` | Оставить известные |
| `.size` | Атрибут: общее число элементов |
| `np.quantile(..., [0.25, 0.5, 0.75])` | Функция NumPy: квантили, как `quantile` в pandas |

```text
Известных возрастов: 714
25%, 50%, 75%: [20.125 28.    38.   ]
```

Совпадает с `describe()` из части 2 (там 20.12 после округления).

| | pandas | NumPy |
|---|---|---|
| Пропуски в `mean`, `median` | Пропускает по умолчанию | Даёт `nan`; нужны `nanmean`, `nanmedian` |
| Найти пропуски | `s.isna()` | `np.isnan(arr)` |
| `quantile` с `nan` | Пропускает | `np.quantile` вернёт `nan` — сначала убрать маской |

**Типичные ошибки.**
- Получить `nan` от `np.mean` и решить, что данные сломаны. Это поведение по умолчанию.
- Искать пропуски через `ages_array == np.nan` → всегда `False` (как в части 3).
- `np.isnan` на массиве строк → ошибка: функция работает только с числами.

**Банковский пример** (тот же `amounts`):

```python
print("Среднее:", np.mean(amounts))
print("nanmean:", np.nanmean(amounts))
print("nanmedian:", np.nanmedian(amounts))
print("Больше 100 000:", amounts[amounts > 100000])
```

```text
Среднее: nan
nanmean: 367450.0
nanmedian: 132500.0
Больше 100 000: [ 250000. 1200000.]
```

Без `print` Jupyter показал бы только последнюю строку и в другом виде: `array([ 250000., 1200000.])`.

Средняя операция 367 450 при медиане 132 500 — одна крупная операция на 1.2 млн сдвигает среднее. Средняя сумма посчитана по 4 операциям из 5.

### 5.5 Сверка pandas и NumPy: std, ddof, isclose

**Что это.** Проверка, что две библиотеки дают одно и то же. `ddof` — аргумент, задающий знаменатель стандартного отклонения. `np.isclose` — сравнение дробных чисел с допуском.

**Зачем.** Одинаковые на вид функции в разных библиотеках могут считать по-разному.

```python
print("pandas std:", df["Age"].std())
print("NumPy std:", np.nanstd(ages_array, ddof=1))
print("Средние совпадают:", np.isclose(df["Age"].mean(), np.nanmean(ages_array)))
```

```text
pandas std: 14.526497332334042
NumPy std: 14.526497332334042
Средние совпадают: True
```

| | pandas `std()` | NumPy `np.std`, `np.nanstd` |
|---|---|---|
| `ddof` по умолчанию | 1 → делим на `n − 1` (выборочное) | 0 → делим на `n` |
| `Age` | 14.5265 | 14.5163 без `ddof=1` (посчитано отдельно) |

Разница мала при 714 значениях, но на маленьких выборках заметна.

**Почему `isclose`, а не `==`.** Дробные числа хранятся приближённо: `0.1 + 0.2 == 0.3` → `False`, а `np.isclose(0.1 + 0.2, 0.3)` → `True`. Две библиотеки могут суммировать в разном порядке и разойтись в последнем знаке.

**Типичные ошибки.**
- Сравнивать `std` из pandas и NumPy без одинакового `ddof` и искать «баг».
- Сравнивать дробные результаты через `==`.
- Округлить до проверки (`round(..., 2)`) и не заметить реального расхождения.

### 5.6 Гистограмма

**Что это.** График распределения **числовой** величины: ось X делится на интервалы (bins), высота столбца — сколько значений попало в интервал.

**Зачем.** Увидеть форму распределения: где основная масса, есть ли хвосты и отдельные группы.

```python
fig, ax = plt.subplots(figsize=(8, 4))
ax.hist(df["Age"].dropna(), bins=16, color="steelblue", edgecolor="white")

ax.set_xlabel("Возраст, лет")
ax.set_ylabel("Количество пассажиров")
plt.tight_layout()
plt.show()
```

|---|---|
| `plt.subplots(...)` | Функция matplotlib (`plt` из `import matplotlib.pyplot as plt`). Создаёт рисунок и область графика |
| `fig, ax = ...` | Функция вернула **два** объекта; Python раскладывает их в две переменные по порядку. `fig` — весь рисунок (`Figure`), `ax` — область с осями (`Axes`), на ней рисуют |
| `figsize=(8, 4)` | Кортеж: ширина и высота в дюймах |
| `ax.hist(...)` | Метод `Axes`: гистограмма. Данные — `Series` известных возрастов |
| `bins=16` | Число интервалов |
| `color=`, `edgecolor=` | Цвет столбцов и их границ (названия цветов — строки) |

### 5.7 Столбчатая диаграмма

**Что это.** График количеств по **категориям**: один столбец на категорию.

**Зачем.** Сравнить размеры групп.

```python
fig, ax = plt.subplots(figsize=(7, 4))
```

#### Выжимка для конспекта

1. Массив NumPy — значения одного типа, без индекса и названий. pandas построен на нём.
2. Арифметика над массивом идёт поэлементно; над списком Python — нет.
3. В pandas агрегаты — методы (`s.mean()`), в NumPy обычно функции (`np.mean(arr)`).
4. NumPy не пропускает `nan`: `np.mean` → `nan`. Нужны `nanmean`, `nanmedian` или маска `~np.isnan`.
5. `std`: pandas `ddof=1`, NumPy `ddof=0`. Сравнивать с одинаковым `ddof`.
6. Дробные сравнивать через `np.isclose`, не `==`.
7. `fig, ax = plt.subplots()`; рисую методами `ax`, всегда подписываю оси.
8. Числа → `hist`, категории → `bar` по `value_counts`.
9. Гистограмма возраста описывает 714 известных значений, не всех 891.
